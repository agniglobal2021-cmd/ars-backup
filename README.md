# Ars Backup

Плагин Obsidian для независимого бэкапа хранилища. Раз в две недели он собирает заметки в архив, шифрует его прямо на устройстве и отправляет письмом на почту. Сами заметки почтовые сервисы не видят: они уходят только шифром.

Работает на iPhone и iPad, компьютер не нужен.

## Как устроено

- **Архив** — обычный zip: заметки, вложения, скрытые папки вроде `.diary` и настройки Obsidian. Файлы книг, код плагинов и настройки с паролями (LiveSync, BRAT) в архив не входят.
- **Шифрование** — [age](https://age-encryption.org), открытый формат. Ключи постквантовые (`age1pq1…`): архивы годами лежат в почте, поэтому шифр рассчитан и на будущие квантовые компьютеры.
- **Ключи.** Открытый ключ запирает архивы и лежит в заметке «Бэкапы». Секретный открывает их и есть только у владельца: в менеджере паролей и на бумаге. На устройствах и в настройках плагина его нет.
- **Почта** — через HTTPS-API [Resend](https://resend.com). Архив больше 15 МБ делится на части, каждая уходит отдельным письмом.
- **Журнал** — та же заметка «Бэкапы». По ней устройства понимают, что бэкап уже сделан, и не повторяют его.

## Установка

1. Поставь плагин BRAT из каталога плагинов Obsidian.
2. BRAT → **Add Beta plugin** → `agniglobal2021-cmd/ars-backup` → **Add Plugin**.
3. Включи Ars Backup в **Сторонние плагины**.

## Настройка

1. Зарегистрируйся в Resend тем адресом, на который хочешь получать архивы. Без своего домена Resend отправляет письма только на него.
2. В Resend открой **API Keys** → **Create API Key**, доступ **Sending access**.
3. В настройках Ars Backup нажми **Создать ключи**, сохрани секретный ключ в менеджер паролей и на бумагу, затем вставь его обратно для проверки.
4. Укажи адрес почты и ключ Resend.
5. Нажми **Отправить** и проверь письмо. В первый раз оно может попасть в спам.

## Восстановление

**В Obsidian.** Сохрани вложение из письма в «Файлы» и выполни команду **Ars Backup: Восстановить из архива**. После ввода секретного ключа можно:

- **сверить с хранилищем** — ничего не меняет, показывает, что изменилось и что удалено;
- **вернуть недостающие** — возвращает удалённые файлы, существующие не трогает;
- **сделать копию в отдельной папке** — распаковывает весь архив рядом.

**Без Obsidian** — программой age на любом компьютере:

```sh
# если частей несколько, сначала склей их
cat ArsMemoria-2026-11-05-1430.zip.age.* > ArsMemoria-2026-11-05-1430.zip.age
# ключ.txt — файл с одной строкой: секретный ключ
age -d -i ключ.txt ArsMemoria-2026-11-05-1430.zip.age > архив.zip
```

Постквантовые ключи поддерживает age начиная с версии 1.3.

## Разработка

```sh
npm install
npm test        # логика плагина на хранилище в памяти; AGE_BIN=путь/к/age проверит и официальной программой
npm run build   # main.js для релиза
```
